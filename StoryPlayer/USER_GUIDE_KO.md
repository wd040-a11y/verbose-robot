# RPG Story Player 통합판 사용법

게임 추출 ZIP을 등록하고 장소와 사건을 선택한 뒤 **감상하기**를 누릅니다. 기본 스토리 감상은 게임 명령을 실행하지 않고 원본의 각 페이지를 별도로 보여줍니다. 페이지를 펼치면 대사, 선택지, 분기 경계와 공통 이벤트를 확인할 수 있습니다. 분기 경계 양쪽의 대사는 하나의 실제 진행 경로가 아닙니다.

CG는 **리소스**에서 이미지 ZIP을 연결한 후 **이 CG 보기**로 엽니다. 이미지가 없어도 대사는 열람할 수 있습니다. 정적 감상의 변수 참조와 텍스트 제어 구문은 원문으로 남습니다. 현재 상태의 값으로 임의 치환하지 않습니다.

**원작 진행 재현 · 임시 상태**는 기존 인터프리터를 복사한 상태에서 실행합니다. **저장 반영**은 기본 세계 상태를 변경합니다. 미지원 스크립트와 플러그인에서 중단되면 기본 스토리 감상으로 원문을 확인할 수 있습니다. 이전 버튼과 대화 기록 이동은 실행 중인 장면의 상태를 함께 복원합니다.

**콘텐츠 접근성 검사**는 게임 전체 맵의 페이지를 검사하고 대사·선택지·CG·불확정 내용을 집계합니다. 실행 검사는 초기 상태와 첫 선택지, 페이지당 500회 표시 경계로 제한됩니다. 모든 분기를 검증한 수치가 아닙니다. 검사 JSON을 저장할 수 있습니다.

**AI 분석**에서는 이미지가 없는 분석 작업 ZIP과 고정 지침을 내보내고 결과 JSON을 가져옵니다. 참조 ID와 번역 제어 토큰을 검증하고 충돌은 자동 덮어쓰지 않습니다. 분석된 의미는 원본 실행 명령을 바꾸지 않습니다.

## 현재 한계

- 실제 게임 패키지의 이번 통합판 재검사는 수행하지 못했습니다. 이전 버전 호환성 수치를 이번 결과로 사용하지 않습니다.
- iOS 실기기 미검증. Safari에서는 웹주소를 열고 파일 앱의 ZIP을 선택합니다. 브라우저 저장소 삭제 시 로컬 저장이 지워지므로 상태를 내보내 보관하세요.
- 정적 감상은 원본 열람이며 원작의 전체 이야기 순서나 스크립트 생성 대사를 자동 복원하지 않습니다.
- CG 정적 미리보기는 원본 화면의 모든 겹침·애니메이션을 재현하지 않습니다. 실행 모드의 기존 CG 렌더러는 유지됩니다.
- 종료 후 저장 상태와 기록은 유지되지만 진행 중인 명령 스택의 완전한 재개는 지원하지 않습니다.
- 캐릭터 초기 능력치 미리보기는 게임별 플러그인 보정이 포함된 현재 능력치가 아닙니다.
