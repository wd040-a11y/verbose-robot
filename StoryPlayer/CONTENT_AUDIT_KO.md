# 콘텐츠 접근성 검사

1. 기존 게임 ZIP을 불러옵니다.
2. 리소스 화면에서 필요한 이미지·영상 ZIP을 연결합니다.
3. 상단 **콘텐츠 접근성 검사**를 누릅니다.
4. 진행률이 완료되면 **보고서 저장**으로 JSON을 저장합니다.

보고서는 페이지·맵·이벤트 위치, 원본 명령 ID, 콘텐츠 종류, 관찰된 선택지 분기, 원인별 통계와 미확정 실행 효과를 기록합니다. 이미지·영상 바이너리, 대사 원문, 암호화 키는 포함하지 않습니다. 외부 AI API를 호출하지 않습니다.

- `accessible`: 제한된 정적 탐색에서 표시 지점이 관찰됨. 원작 실행 정확성의 보증은 아닙니다.
- `partial`: 일부 분기만 관찰되었거나 미디어 디코딩이 미확인입니다.
- `unknown`: 관찰되지 않았거나 검사 한도에 도달했습니다.
- `resource_missing`: 연결 패키지에서 파일을 찾지 못했습니다. 원본 게임에 파일이 없다는 뜻이 아닙니다.

페이지당 최대 128경로, 경로당 최대 2000 표시 경계를 검사합니다. 제한은 보고서에 기록합니다. 공통 이벤트 콘텐츠는 호출하는 페이지마다 검사하므로 전체 합계는 게임 파일의 고유 명령 수와 다를 수 있습니다. 동영상은 파일 존재만으로 재생 성공으로 판정하지 않습니다. 실제 브라우저에서 재생 버튼을 눌러 코덱 지원을 확인할 수 있습니다.

CG 표시·변경·삭제는 각각 감상 지점으로 남습니다. 대사 없이 그림만 표시했다가 지워지는 장면도 다음 버튼으로 한 단계씩 볼 수 있고 이전으로 되돌릴 수 있습니다.

실제 사용자 게임은 개발 환경에 없습니다. 테스트 결과는 합성 자료 기준이며 실제 게임의 호환성 성공률은 발표하지 않습니다.
