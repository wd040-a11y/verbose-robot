# 메인 화면 스토리 감상

기본 감상은 팝업이 아니라 메인 대사 화면에서 실행됩니다. 선택지는 한 경로씩 표시하며 조건 분기는 직접 경로를 선택합니다. 이전 버튼과 기록에서 돌아가면 그림과 선택 경로가 함께 복원됩니다. 세계 저장에는 반영하지 않습니다.

기본 목록은 대사·선택지·CG·영상 또는 공통 이벤트 콘텐츠가 있는 이벤트만 표시합니다. 상황 선택에서 페이지를 바꿀 수 있습니다. 전체 원문은 감상 설정의 고급 열람 기능입니다.

CG는 원본 좌표계를 가로·세로 공간에 맞춰 축소합니다. 감상 설정의 CG 전체 보기에서 개별 원본을 선택하고 확대 후 스크롤할 수 있습니다. 동영상 명령은 현재 동영상 열기로 연결 자료를 재생합니다. 코덱 지원과 파일 존재 여부는 다릅니다.

콘텐츠 접근성 검사 JSON에는 패키지의 미디어 연결 여부가 포함됩니다. 원본 게임 폴더를 검사하지 않았으므로 연결 자료에 없다는 사실을 원본에 없다는 뜻으로 해석하지 않습니다.

## 정확성 범위

- 플러그인·스크립트는 실행하지 않습니다. 이후 원문을 계속 볼 수 있지만 그 실행 효과는 미확정입니다.
- 정적 감상의 변수·파티 이름 참조는 임의 값으로 치환하지 않습니다.
- 선택지와 조건 분기, 중첩, 공통 이벤트 호출은 경로를 나누어 탐색합니다. 공통 이벤트 순환은 제한합니다.
- 반복과 레이블 점프는 경계 안내 후 원본 구간 탐색으로 전환합니다. 해당 구간을 원작의 실제 이어지는 순서로 보장하지 않습니다.
- GIF/WebP는 브라우저 이미지 지원을 이용합니다. MP4/WebM은 컨테이너를 인식하고 재생 오류를 안내하며 모든 코덱을 보장하지 않습니다.
- 원본 게임 전체 사건 순서의 자동 복원은 미완성입니다. 기존 근거가 있는 호출 관계와 오프라인 분석 자료를 보존합니다.
- 실제 게임 데이터 검증과 iOS 실기기 검증은 수행하지 못했습니다. 사용자 제공 5,969페이지 기준치는 이번 버전 검사 결과가 아닙니다.
