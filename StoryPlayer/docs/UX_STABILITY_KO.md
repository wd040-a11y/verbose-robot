# 감상 경험 및 ZIP 안정화

기본 감상은 그림 명령마다 멈추지 않고 대사와 선택지를 중심으로 진행합니다. CG 전용 장면은 한 번의 감상 단계로 표시하며, 순간적으로 지나간 그림은 감상 설정의 ‘지나간 CG 기록’에서 확인합니다. 이전 버튼은 선택 경로와 그림 상태를 함께 복원합니다.

콘텐츠가 확인된 장소만 기본 표시하며 전체 장소 보기로 전환할 수 있습니다. 검색은 장소·이벤트 이름과 원문 대사를 대상으로 합니다. 단일 CG는 비율을 유지해 맞춤 표시하고, 여러 그림은 원본 좌표계를 유지합니다. 원본 장면 보기와 전체 이미지 보기는 감상 설정에서 선택합니다.

## 대용량 ZIP
256MiB보다 큰 압축파일 또는 해제 총량은 목록을 읽고 필요한 파일만 지연 로딩합니다. ZIP 전체를 메모리나 IndexedDB로 복사하지 않습니다. 원본 ZIP을 보관해야 하며 앱을 재실행하면 같은 ZIP을 다시 선택해야 합니다. 저장 상태는 유지됩니다. 리소스 ZIP도 재연결해야 합니다. 연결 대기 상태는 파일 형식이나 코덱 검증 성공을 뜻하지 않습니다.

안전 한도: 파일 30,000개, JSON 하나 32MiB, 읽는 미디어 하나 128MiB, 플러그인 원문 4MiB. 16MiB를 넘는 파일의 압축률이 1,000배를 초과하면 읽지 않습니다. 사용하지 않는 원본 보관 파일은 압축 해제하지 않습니다. 파일 이름·크기·CRC 오류를 구분하며 안전하지 않은 경로를 거부합니다. 브라우저 저장소나 메모리가 부족하면 작은 스토리 ZIP과 별도 미디어를 사용하세요.

추출기 GUI는 맵과 이벤트가 있는 결과에 Story.zip을 추가합니다. 원본 명령·조건·분기·리소스 메타데이터를 포함하고 미디어 바이너리와 원본 보관 파일은 제외합니다. assets 폴더를 별도로 ZIP으로 묶어 리소스로 연결할 수 있습니다. 플러그인 원본을 제외한 경량 패키지의 고급 호환 분석에는 제한이 있습니다. 전체 추출 폴더는 삭제하지 않습니다.

## 검증 범위
합성 데이터로 대사 A/B/C와 그림 변경·삭제, CG 전용 장면, 분기 복원, 빈 장소 필터, 실제 2GiB 초과 ZIP64 파일의 뒤쪽에 있는 JSON과 이미지 읽기를 검사합니다. 대용량 미디어 한 파일 전체 재생, 모든 ZIP64 구현, 모든 코덱을 보장하지 않습니다. 실제 사용자 게임과 iOS 실기기는 작업 환경에 없어 미검증입니다. 기존 고급 인터프리터·저장 기능과 로컬 콘텐츠 검사 JSON 내보내기는 유지됩니다.

사용자는 게임 ZIP 선택 → 필요시 리소스 ZIP 연결 → 장소와 장면 선택 → 콘텐츠 접근성 검사 → JSON 저장 순서로 확인하면 됩니다. 원본에 없는 콘텐츠나 미확정 실행 효과를 복원했다고 보고하지 않습니다.
