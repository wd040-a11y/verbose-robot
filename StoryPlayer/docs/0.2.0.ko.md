# 0.2.0 변경 및 검증 범위

## 실제 패키지 비교

동일 ZIP SHA-256과 System 초기 상태, 페이지별 새 상태, 첫 번째 선택지, 최대 2,000회 재개·100,000명령으로 1,181개 맵 이벤트 페이지를 검사했습니다. 공통 이벤트는 호출된 경우만 실행합니다. 모든 분기·병렬 이벤트·실제 플레이 경로 검증이 아닙니다.

| 결과 | 0.1 | 0.2 |
|---|---:|---:|
| 완료 | 671 | 1,160 |
| 미지원 중단 | 510 | 21 |
| 실행 한도 초과 | 0 | 0 |

신규 완료 489개. 기존 완료 페이지의 완료→실패 회귀 0개. 기존 완료 페이지의 기존 상태 필드(스위치·변수·셀프 스위치·소지품·금액·파티·위치·그림) 차이 0개. 새로 완료된 모든 경로의 상태가 원본 엔진과 같다는 뜻은 아닙니다. 완료 중 161개는 이동/시간 간소화가 기록되어 있습니다.

남은 중단: 205 이동 경로 4개, 355 임의 스크립트 1개, 356 플러그인 명령 16개. 보고서의 각 페이지 ID·실행 경로 해시·중단 원인으로 비교할 수 있습니다. 게임 대사와 스크립트 본문은 보고서에 포함하지 않습니다.

## 실행 정책

A: 상태/흐름을 실행. B: 확인된 표현 효과를 생략하고 기록. C: 상태를 저장하고 연출을 간소화. D: 미확인 명령에서 해당 실행만 중단. UI에서 원인·명령 위치·변경된 상태 항목을 확인하고 실행 전 상태로 복원할 수 있습니다.

- 205: 경로 전체를 사전 검사합니다. 스크립트 45·알 수 없는 명령은 실행하지 않습니다. 대기 경로의 스위치 27/28, 방향·그래픽·속도·투명도 등을 처리합니다. 505는 편집기 연속 데이터이므로 재실행하지 않습니다.
- 충돌·통행 가능성은 시뮬레이션하지 않습니다. 요청 좌표와 실제 확인 좌표를 구분합니다. 미확정 좌표/방향을 뒤에서 읽으면 중단합니다. 통과할 수 없는 이동 뒤의 상태 변경이나 비동기 경로의 스위치 변경은 임의로 적용하지 않습니다. 반복+대기는 종료를 보장할 수 없어 중단합니다.
- 211: 플레이어 투명 상태. 322: 액터 캐릭터/얼굴 이름·인덱스 및 MV/MZ 배틀러 이름. 파티 선두의 캐릭터 상태도 갱신합니다.
- 111/122: 알려진 소지품·장비·액터 필드·방향·타이머·변수/게임 데이터 및 시드 난수. 등록되지 않은 액터 상세 상태·전투 적 상태·실시간 입력은 미지원입니다. 타이머는 시작/정지를 저장하지만 사용자 대기 이후 정확한 경과 시간을 추정하지 않습니다.
- 난수 상태와 호출 횟수는 저장됩니다. 같은 시드/상태/실행 경로에서 재현됩니다. MV/MZ는 변수별 난수, VX Ace는 범위 변수에 공통 피연산자를 적용합니다.

## 플러그인 어댑터

`src/plugins/registry.js`는 추출 메타데이터와 실제 원본 바이트의 SHA-256을 대조합니다. 이름만 같은 플러그인·다른 버전·의존성 미확인은 허용하지 않습니다.

검토한 TMBalloonLoop의 `setBalloonLoop`는 캐릭터 풍선 반복 상태를 저장합니다. GetInformation의 `ShowInfo`는 검토된 CommonPopupCore 의존성을 확인하고 일반 문자열을 메시지로 보여주며 infoLog를 보존합니다. 동적 컨텍스트 치환은 미지원입니다. 팝업 시간·음향 연출은 간소화합니다. PictureCallCommon의 `P_CALL_CE`는 입력과 공통 이벤트 예약을 요구하므로 미지원입니다. MZ 357도 등록된 검증 어댑터가 없으면 중단합니다.

## 이미지

logical_path/source_path/output_path 및 추출기의 해시 디렉터리를 기준으로 연결합니다. 중복 후보는 모호함으로 보고합니다. PNG/JPEG/WebP의 형식·크기를 검사하고 브라우저에서 디코딩합니다. 파일별 실패를 보고하며 다른 이미지 연결은 계속됩니다.

얼굴: MV/MZ 144×144, VX Ace 96×96, 4열 2행. CG: 번호순 겹침, 원점, 좌표, 배율, 알파, 기본 합성 표시. 이동 명령은 최종 정적 상태를 표시하며 원본 시간 애니메이션과 동일하지 않습니다. 누락 이미지는 대체 표시하고 나중에 ZIP을 추가하면 다시 연결합니다.

실제 제공 패키지에는 이미지가 없으므로 실제 게임 CG를 확인했다고 주장하지 않습니다. 이미지 검증은 직접 만든 얼굴 시트와 CG로 수행합니다.

## 테스트와 배포

자동 테스트 32개: 기존 인터프리터 회귀, 지시서 A–M 범위, 경로 스크립트 거부, 난수 재현, 미확정 상태 거부, 저장 호환, ZIP 경로 및 오류 집계. GUI 검사는 얼굴 픽셀, CG 겹침·이동·삭제, 누락 이미지, 선택지/스위치, 임시 감상/복원, 재실행 저장, 좁은 화면을 검사합니다.

Windows 및 브라우저 결과는 해당 GitHub Actions 실행의 `StoryPlayer-Test-Evidence` 아티팩트에 기록합니다. 실행되지 않은 CI 결과를 이 문서에서 통과로 간주하지 않습니다. Windows와 웹의 `build-info.json` source_sha256으로 공통 소스 일치를 확인합니다. iOS 실기기는 미검증입니다.

## 계속 미지원

전체 전투·원본 맵 충돌/자동 이동 스케줄러·병렬 이벤트 스케줄링·임의 JavaScript/Ruby 실행·모든 플러그인·모든 메시지 제어문자·정확한 화면 효과/음향 타이밍·AI 번역/스토리 정렬. ZIP 가져오기는 최대 30,000파일, 단일 128MiB, 총 2GiB, JSON 32MiB 제한입니다. 자동 Windows/웹 상태 동기화는 없습니다.

- MV 공식 코어: https://github.com/rpgtkoolmv/corescript/tree/master/js/rpg_objects (Game_Interpreter, Game_Character, Game_CharacterBase)

실제 게임의 원본 코드는 분석 자료로만 읽었으며 실행하지 않았습니다.

새 파일은 IndexedDB에 바이트 배열과 MIME 정보를 저장합니다. 이전 Blob 저장 형식은 읽을 때 그대로 지원하며 저장소를 삭제하거나 초기화하지 않습니다. ZIP은 순차 스트림으로 읽고 파일별 CRC·크기 제한을 유지합니다.
