# RPG Story Player 0.1

개발 중인 이벤트 재생기입니다. RPGMakerExtractor 1.1.0 패키지를 읽습니다.

## 사용
1. Windows 배포 EXE를 더블클릭합니다. Python이나 CMD가 필요하지 않습니다.
2. 추출 ZIP을 선택합니다. 이미지는 없어도 됩니다.
3. 장소와 이벤트의 ‘일반 실행’을 선택합니다. 대사는 ‘다음’, 선택지는 해당 버튼으로 진행합니다.
4. 조건이 맞지 않는 페이지는 ‘임시 상태로 강제 감상’으로 별도 상태에서 실행할 수 있습니다.
5. ‘리소스 ZIP 추가’에서 원래 img/pictures 등의 경로를 유지한 PNG/JPEG/WebP ZIP을 넣으면 기존 참조에 연결됩니다. 암호화 이미지는 추출기에서 먼저 복원해야 합니다.

상태 변경은 로컬 IndexedDB에 저장됩니다. 스냅샷 저장·복원과 실행 전 되돌리기를 지원합니다. 브라우저 저장소를 지우면 저장한 패키지와 상태도 없어집니다.

## 지원 범위
대사, 선택지/취소 분기, 스위치·변수·셀프 스위치 조건 및 변경, 상위 페이지 우선 선택, 공통 이벤트 호출, 루프/탈출, 기본 소지품·금액·파티 변경, 위치 이동 기록, 그림 표시/이동의 최종 상태와 삭제를 처리합니다. 원본 raw.code/parameters/indent를 사용합니다.

스크립트·플러그인은 실행하지 않습니다. 미지원 상태 명령이나 조건은 해당 이벤트에서 중단하며 이미 실행된 상태는 되돌릴 수 있습니다. 다른 이벤트는 계속 실행할 수 있습니다. 오디오·화면 전환 등 지정한 표현 명령은 생략하고 기록합니다. 이동 경로는 스위치·스크립트를 포함할 수 있어 생략하지 않습니다.

## 제한
- 완전한 원본 게임 엔진이 아닙니다. 전투, 이동 경로, 상세 캐릭터 상태, 장비 효과, 타이머/입력 조건, 난수/게임 데이터 피연산자, 플러그인 호환 처리는 미구현입니다.
- 자동/병렬 이벤트는 자동 스케줄링하지 않습니다. 사용자가 이벤트를 선택해 실행합니다.
- 맵은 선택 목록으로 표시하며 타일 지도·캐릭터 이동 시뮬레이션은 없습니다.
- 그림 애니메이션의 시간·배치·합성 및 메시지 제어문자 전체를 원본과 동일하게 렌더링하지 않습니다.
- 현재 실제 검증 자료는 MV 패키지입니다. MZ/VX Ace 전체 호환을 보증하지 않습니다.
- iPhone 실기기/Safari 검증과 원본 엔진 대조 테스트는 아직 수행하지 않았습니다.
- ZIP 가져오기를 지원하며 폴더 직접 가져오기는 미구현입니다. 파일 30,000개, 단일 파일 128 MiB, 총 해제 크기 2 GiB, JSON 32 MiB 한도가 있습니다.

## 개발/검증
`npm ci`, `python scripts/make-fixture.py`, `npm test`, `npm run build`.
fixture 생성기는 저장소의 추출기와 jsonschema/Pillow를 사용합니다. Windows 패키징: `npm run dist:win`. GitHub Actions가 Windows EXE를 빌드하고 `e2e/player.mjs`로 패키징된 GUI를 검증합니다.
`node scripts/audit-package.mjs /path/to/package.zip`은 실제 패키지를 로컬에서만 검사하며 통계만 reports에 남깁니다. 각 페이지를 초기 상태와 첫 선택지로 검사하므로 모든 분기 검증은 아닙니다.

원본 게임 파일·대사·스크립트는 저장소와 CI에 포함하지 않습니다. 합성 샘플은 자체 제작했습니다.
