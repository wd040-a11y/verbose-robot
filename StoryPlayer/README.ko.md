# RPG Story Player 0.2.0

RPGMakerExtractor 패키지의 맵·NPC를 선택해 대사와 선택지를 재생합니다. 기존 0.1 저장 데이터와 스냅샷을 유지하며 부족한 상태 필드를 추가합니다.

## Windows와 iPhone/iPad에서 사용

- Windows: GitHub Actions의 `RPGStoryPlayer-Windows` 아티팩트를 받아 압축을 풀고 EXE를 더블클릭합니다. Python·CMD 설치는 필요 없습니다.
- 웹: https://rpg-story-player-wd040.dionisauce.chatgpt.site/ 에서 같은 기능을 사용합니다. 소유자 계정 로그인이 필요합니다. iPhone/iPad에서는 Safari로 열고 파일 선택에서 추출 ZIP과 리소스 ZIP을 불러옵니다. EXE는 iOS에서 실행되지 않습니다.
- iOS 실기기 검증은 아직 하지 않았습니다. 데스크톱 WebKit 테스트도 실기기 Safari 검증을 대신하지 않습니다.

1. 추출 ZIP을 불러온 뒤 장소와 NPC의 **일반 실행**을 선택합니다.
2. **다음**과 선택지 버튼으로 진행합니다. 원문을 번역하지 않습니다.
3. 이미지가 없어도 대사와 상태 변경은 계속됩니다. **리소스 ZIP 추가** 후 연결 결과와 이미지 목록에서 검색·미리보기를 확인합니다.
4. 이미지 ZIP은 원래 `img/faces`, `img/pictures`, `Graphics` 또는 추출기의 `assets/images` 상대 경로를 유지하세요. 바깥쪽 폴더 이름은 달라도 됩니다. 같은 파일명만으로 연결하지 않습니다. 암호화 파일은 추출기에서 먼저 복원해야 합니다.
5. 중단한 이벤트는 **실행 전으로 되돌리기**로 복원할 수 있습니다. 미지원 명령은 다른 NPC의 실행을 막지 않습니다.
6. **임시 상태로 강제 감상**은 별도의 상태로 진행합니다. 사용자가 명시적으로 반영 버튼을 누르기 전에는 기본 세계를 바꾸지 않습니다.

패키지·이미지·상태는 해당 브라우저/앱의 로컬 IndexedDB에 저장됩니다. 웹과 Windows 간 자동 동기화는 없습니다. 저장소를 삭제하면 데이터가 지워집니다. 이전 0.1에서 가져온 패키지는 플러그인 원본이 저장되지 않았을 수 있으므로 검증된 플러그인 처리가 필요하면 같은 추출 ZIP을 다시 가져오세요.

## 0.2 주요 변경

- 이동 경로 205 내부를 검사하고 스위치 변경을 반영합니다. 505는 중복 실행하지 않습니다. 스크립트·불명확한 비동기 상태 변경은 중단합니다.
- 211은 플레이어 투명 상태, 322는 액터 그래픽 상태를 저장합니다.
- 시드 난수, 알려진 게임 데이터·방향·타이머 조건을 지원합니다. 모르는 상태를 임의로 추측하지 않습니다.
- SHA-256이 검토된 원본과 일치하는 제한된 플러그인 명령만 어댑터로 처리합니다. 원본 JavaScript/Ruby는 실행하지 않습니다.
- 얼굴 시트 인덱스에 맞춘 잘라내기, 여러 CG의 순서·위치·원점·확대율·투명도·삭제를 표시합니다.
- 이미지 연결 수와 실패 이유, 이벤트 실행과 독립적인 이미지 미리보기를 제공합니다.

자세한 지원 범위·비교 방법은 [0.2 변경 및 검증 문서](docs/0.2.0.ko.md), 페이지별 결과는 [호환성 보고서](reports/compatibility-0.2.json)를 참조하세요.

## 개발

`npm ci`, `python scripts/make-fixture.py`, `npm test`, `npm run build`.
샘플 생성은 저장소 추출기와 Python jsonschema/Pillow를 사용합니다. `npm run dist:win`은 Windows 포터블 EXE를 빌드합니다. CI는 패키징된 Electron 및 Chromium/WebKit에서 같은 GUI 시나리오를 검사합니다.

`node scripts/compare-package.mjs /path/to/package.zip`은 0.1과 0.2를 같은 정책으로 비교합니다. 실제 게임 원본은 저장소·CI·웹 배포에 포함하지 않습니다. CI 이미지는 자체 제작 합성 자료입니다.
