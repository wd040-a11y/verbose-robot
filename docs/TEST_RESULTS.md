## 대규모 측정

최종 실행의 H 테스트: **107.60초, tracemalloc 최고 78.1MiB**. 전체 32개 테스트 실행 시간은 118.23초입니다. tracemalloc은 Python 할당 추적 수치이며 전체 프로세스 RSS가 아닙니다. 추적 자체의 실행 비용이 포함되어 일반 실행 속도와 같지 않습니다. 테스트는 최고 Python 할당 300MiB 미만과 명령/이벤트 보존을 확인합니다. 단일 거대 맵과 수백만 이벤트까지 일반화하는 벤치마크는 아닙니다.
