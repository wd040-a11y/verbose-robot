# 사용 설명서

## 게임 폴더와 출력 위치

`Game.exe`가 있는 배포 폴더 또는 RPG Maker 프로젝트 폴더를 선택합니다. 내부 `www` 유무에 관계없이 `System.json`, `MapInfos.json`, 맵 파일과 엔진 파일을 함께 확인합니다. 중간 폴더와 데이터·리소스 폴더의 재배치도 검색합니다. 여러 게임이 있으면 데이터 루트 목록에서 하나를 선택하세요.

엔진 파일이 없고 단서가 부족하면 MV/MZ를 확정하지 않습니다. 엔진 파일과 프로젝트 파일이 서로 다른 엔진을 가리킬 때도 중단합니다. MZ `advanced` 필드만 있는 경우 낮은 신뢰도로 표시합니다. 파일이 암호화된 별도 패키지 안에만 있거나 XP/VX/VX Ace 자료이면 지원하지 않습니다.

결과는 **새 폴더 또는 빈 폴더**에 저장합니다. 이미 결과가 있는 폴더에는 덮어쓰지 않습니다. 원본 폴더 자신이나 원본의 상위 폴더를 출력으로 사용할 수 없습니다. 원본 내부의 새 하위 폴더는 사용할 수 있고, 그 출력은 검색에서 제외됩니다. 원본 폴더 바깥의 별도 위치를 권장합니다.

## 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| 원본 JSON 보존 | 켜짐 | JSON 원본을 source_archive에 보관 |
| JavaScript·플러그인 소스 | 켜짐 | 모든 발견된 JS 원문 보관. 실행하지 않음 |
| 이미지·효과 추출 | 켜짐 | img/effects 리소스 복사와 색인 |
| 표준 암호화 복원 | 켜짐 | System 키와 표준 헤더로만 복원 |
| 오디오 포함 | 꺼짐 | 켜면 오디오 복사·표준 복원 |
| 영상 포함 | 꺼짐 | 켜면 영상 파일 복사 |
| LLM 자료 생성 | 켜짐 | 로컬 JSON/JSONL 생성. API 호출 없음 |
| 상세 오류 보고서 | 켜짐 | 이벤트별 원형 비교 세부 보고서 추가. 필수 오류·검증 보고서는 항상 생성 |
| 타일 배열 보존 | 켜짐 | 맵 타일 원문 배열을 맵 상세 파일에 포함 |
| 키 포함 System.json 원본 | 꺼짐 | source_archive의 System.json에 키를 포함하는 별도 선택 |

**System.json 키 예외:** 기본 설정의 source_archive/data/System.json은 `encryptionKey` 필드가 제거된 JSON입니다. 원본과 바이트가 같다고 표시하지 않으며, source_inventory의 `representation`은 `redacted_json`입니다. 원본의 SHA-256은 기록합니다. 그 외 JSON/JS 원본은 보관 옵션을 켜면 정확한 바이트를 복사합니다. 키 포함 옵션을 선택하더라도 normalized/와 llm_input/에는 키를 넣지 않습니다.

타일 보존과 원본 JSON 보존을 모두 끄면 타일 배열을 복구할 수 없습니다. 이미지·오디오 복사를 꺼도 원본 파일 메타데이터와 명령의 참조 관계는 남습니다. 플러그인 소스 보관을 끄면 설정과 호출 위치는 남지만 원문은 재분석할 수 없습니다.

게임 식별자는 비워 두면 자동 생성됩니다. 게임 업데이트 전후에도 같은 패키지 이름공간을 유지하고 싶으면 영문·숫자·`._-` 조합의 고정 식별자를 입력하세요.

## 완료 상태

| state | 의미 |
|---|---|
| complete | 추출·검증 통과, 기록된 문제 없음 |
| complete_with_issues | 경고 또는 알 수 없는 명령 있음. 해당 원형은 보존 |
| partial | 읽기/정규화/리소스 오류가 있어 일부 기능이 누락될 수 있음. 스키마 통과와 별개 |
| invalid | 스키마 또는 원형/개수 검증 실패. 정상 패키지로 취급하면 안 됨 |
| cancelled | 사용자가 중단한 미완성 결과 |
| in_progress | 진행 중이거나 강제 종료로 마무리하지 못한 결과 |

`schema_valid`는 JSON 형식의 유효성입니다. 이것만으로 전체 게임이 완전하게 추출됐다는 뜻은 아닙니다. `state`, 오류, 미해결 참조, `reports/integrity.json`을 함께 확인하세요. `validate` 명령은 출력 형식과 필수 파일을 다시 검사하며 게임 실행 가능성을 보장하지 않습니다.

취소는 파일·명령·스트림 블록 사이에서 적용합니다. 매우 큰 JSON 하나를 읽거나 저장하는 중에는 해당 작업이 끝날 때까지 지연될 수 있습니다. 취소 결과는 `cancelled`로 표시하고 성공으로 표시하지 않습니다. 새 빈 출력 폴더에서 재실행하세요. 기존 결과의 이어받기·변환 캐시는 아직 구현하지 않았습니다.

## 테스트 샘플 실행

`samples/MV`와 `samples/MZ`는 자체 제작 자료입니다. 실제 플레이 가능한 게임 엔진은 포함하지 않았고, 추출기 테스트를 위한 엔진 식별 마커만 있습니다.

```powershell
.\.venv\Scripts\python -m rpgextractor extract samples\MV example_mv
.\.venv\Scripts\python -m rpgextractor extract samples\MZ example_mz
.\.venv\Scripts\python -m rpgextractor validate example_mz
```

샘플의 999번 명령은 의도적인 미지원 테스트입니다. 샘플 JavaScript에는 의도적인 예외 문장이 있지만 추출기는 이를 실행하지 않으므로 영향이 없습니다.

## 문제 해결

- `데이터 루트가 0개`: 게임의 상위 폴더를 선택했는지, JSON 데이터가 별도 보호 패키지 안에만 있는지 확인하세요.
- `MV/MZ를 확정할 수 없음`: `rpg_core.js` 또는 `rmmz_core.js`, 프로젝트 파일이 원래 위치에 있는지 확인하세요.
- `JSON을 읽을 수 없음`: 보고서에 표시된 파일이 UTF-8 JSON인지 확인하세요. 원본을 편집하지 말고 정상 사본에서 다시 시도하세요.
- `리소스 복원 실패`: 손상된 파일, 키 누락, 커스텀 암호화 가능성이 있습니다. 키를 추측하거나 우회하지 않습니다.
- `참조 대상 없음`: 파일 누락, 잘못된 원본 ID, 플러그인의 동적 파일명일 수 있습니다. 보고서의 source_id를 맵 상세 파일에서 찾으세요.
- `링크/재분석 경로`: 심볼릭 링크와 Windows 정션은 의도적으로 읽지 않습니다. 접근 가능한 실제 폴더 사본을 선택하세요.
- 설치 실패: Python 64비트와 버전, 디스크 공간, 설치 시 인터넷 연결을 확인하세요. 추출 시에는 인터넷이 필요 없습니다.
- Windows 보안 경고: 이 소스의 자체 빌드는 코드 서명이 없습니다. 서명·설치 프로그램 제작은 이번 범위에 포함하지 않습니다.
