# 게임 등록·관리 통합 작업

## Windows
‘게임 폴더 열기’를 누르면 포함된 로컬 추출기가 게임을 읽고 CG·음성·영상과 스토리 데이터를 등록합니다. Python 설치나 별도 추출기 실행, ZIP 재압축이 필요하지 않습니다. 게임의 JavaScript/Ruby/실행 파일은 실행하지 않습니다. 후보가 여럿이면 게임 이름·엔진·맵 수·경로로 선택합니다.

등록한 자료는 앱 전용 폴더에 보관하며 필요한 ZIP 구간만 읽습니다. 재실행 후 게임 폴더나 ZIP을 다시 고를 필요가 없습니다. 일부 리소스를 읽지 못해도 남은 콘텐츠를 등록하고 실패 수를 안내합니다. 원본 게임 폴더는 변경하지 않습니다.

## 웹·모바일
Windows 추출기가 만든 **Game.zip 하나**를 불러옵니다. 이 패키지에는 성공적으로 복사·복원한 CG와 선택한 미디어가 포함됩니다. Story.zip은 기존 호환용 텍스트 중심 패키지이며, Game.zip에 중첩하지 않습니다. 큰 ZIP은 브라우저에서 재실행할 때 다시 선택해야 할 수 있습니다. iOS 원본 게임 폴더 직접 추출은 이번 구현에 포함되지 않습니다.

## 게임 관리
같은 패키지를 다시 불러오면 교체(저장 유지) 또는 별도 보관을 선택합니다. 제목만 같다고 같은 게임으로 판단하지 않습니다. System/MapInfos가 달라 패키지 ID가 바뀐 버전은 자동 병합하지 않으며 게임 관리에서 선택해 삭제할 수 있습니다.

삭제에는 확인 화면이 있고, 기본으로 저장·번역·이름·감상 기록을 보관합니다. 동일 패키지를 다시 등록하면 보관한 상태를 불러옵니다. 보관을 해제하고 삭제하면 해당 패키지의 보관 상태도 제거합니다. 원본 게임/사용자가 선택한 ZIP은 삭제하지 않습니다. Windows가 자동 생성한 관리용 게임 데이터는 삭제합니다.

## 탐색
장소는 100개마다 ‘더 보기’로 끝까지 접근합니다. 한국어 표시명과 원문·대사 모두 검색할 수 있습니다. 주점·여관·교회 등의 기본 장소 용어만 사전으로 표시하며 고유명은 미번역 원문으로 표시합니다. 선택한 장소의 한국어 이름을 지정하면 저장됩니다. 이는 전체 일본어 자동 번역이나 스토리 의미 분석이 아닙니다.

장면 카드에 첫 대사 미리보기·콘텐츠 유형·감상 가능한 상황 수를 표시합니다. 대화·선택지·CG·영상으로 필터링할 수 있습니다. 공통 이벤트까지 확인한 콘텐츠 페이지를 기본 감상 대상으로 고르며, 빈 그림 이름을 CG가 있다고 판정하지 않습니다. 메인 스토리 여부와 전체 사건 순서는 아직 자동 확정하지 않습니다.

## 현재 한계
- 외부 AI API/유료 서비스는 사용하지 않습니다. 임의 고유명 전체 번역, 완전한 스토리 순서 복원은 구현하지 않았습니다.
- 실제 사용자 게임은 작업 환경에 없으며 합성 입력으로 검증합니다.
- 폴더 등록 중 취소/이어서 재개, 실패한 네이티브 임시 작업의 자동 청소는 추가 보완이 필요합니다.
- 웹의 브라우저 저장 용량, 영상 코덱, iOS 실기기는 별도 제약이 있습니다.
