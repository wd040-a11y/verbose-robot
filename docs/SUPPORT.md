## 제한 및 미구현

1. **재생 엔진·상태 시뮬레이터·LLM 분석기는 없습니다.** 이벤트 실행, 정확한 도달 가능성, 엔딩 조건 해석, 상태 프리셋 생성, enrichment 병합을 하지 않습니다.
2. 명령을 모두 원형으로 보존하지만 모든 명령을 의미적으로 해석한 것은 아닙니다. 표준 명령 목록 식별과 주요 상태·리소스 참조 추출을 제공합니다. 스크립트·플러그인·메모 태그가 만드는 동적 참조와 커스텀 페이지 조건의 의미는 확정하지 않습니다.
3. MV의 플러그인 명령 문자열은 실제 플러그인 파일에 확정 연결하지 않습니다. MZ는 명시된 플러그인 이름으로 연결합니다. `plugins.js`가 함수 호출/임의 JavaScript 객체식이면 설정을 실행하지 않고 원문과 경고를 남깁니다. 비표준 문자열 문법·주석이 JSON 배열 내부에 있는 형식도 미지원입니다.
4. 특수 암호화·보호 패키지·키 추측·키 복구는 지원하지 않습니다. XP/VX/VX Ace의 RGSS 아카이브는 지원하지 않습니다. 헤더가 변형된 자료는 unsupported_encryption으로 남깁니다.
5. PNG는 시그니처와 Pillow 구조/체크섬 검사를 합니다. OGG/M4A는 시그니처와 컨테이너 경계/필수 박스를 검사하며 **코덱 디코딩·소리 재생·OGG CRC 검사는 하지 않습니다.** 영상/효과 바이너리는 복사·색인만 하며 디코딩 검증은 하지 않습니다.
6. 공통 이벤트의 순환 호출을 펼치지 않으므로 무한 재귀를 만들지 않습니다. 호출 그래프 자체는 기록하지만 순환 컴포넌트/실행 깊이를 계산하지 않습니다.
7. 프로젝트의 기본 상태만 기록합니다. 세이브 파일의 현재 스위치·변수·셀프 스위치를 가져오지 않습니다. 스위치 초기값 false, 변수 초기값 0은 표준 런타임 기본값입니다. 플러그인 초기화에 따른 실제 변경은 실행하지 않습니다.
8. 임의 폴더의 모든 파일을 의미 분석하지 않습니다. 핵심 데이터 디렉터리의 JSON, 발견된 기타 JSON·JS와 img/audio/movies/effects 리소스를 처리합니다. 다른 커스텀 바이너리 디렉터리, URL/원격 리소스, 동적으로 만들어진 파일명은 자동 연결하지 않습니다.
9. **이어받기·증분 캐시·강제 종료 후 복구는 미구현**입니다. 소스/리소스 단위 상태·해시는 남으며, 재시도는 새 폴더에서 합니다. 원자적 파일 교체와 취소 표시를 사용하지만 전체 디렉터리를 트랜잭션으로 커밋하지 않습니다.
10. 스트림 처리는 바이너리 복사/복원에 적용됩니다. JSON 한 파일, 맵 한 개와 전역 참조 인덱스는 메모리에 올립니다. 단일 거대 맵 또는 비정상 JSON/과도한 문자열에 대한 하드 메모리 제한은 없습니다. JSON 파싱/쓰기 중 취소는 지연될 수 있습니다. 수백만 이벤트 규모는 검증하지 않았습니다.
11. 링크와 정션을 거부하지만 다른 프로세스가 동시에 입력 경로를 교체하는 경쟁 조건까지 완전히 방어하는 OS 샌드박스는 아닙니다. 원본은 추출 중 변경되지 않는 로컬 사본으로 처리하세요.
12. JSON Schema는 출력 형식 계약입니다. 원본 손상 파일의 내용을 정상 JSON으로 만들지는 않습니다. 생성된 원본 archive의 손상 JSON은 의도적으로 원형 보존하며 정상 출력 봉투 검사에서 제외됩니다.
13. **Windows EXE 실물 빌드와 Windows 실기 검증은 이 실행 환경에서 수행하지 않았습니다.** PyInstaller 빌드 스크립트와 Windows CI 설정을 제공합니다. 코드 서명·설치 프로그램·자동 업데이트는 없습니다. Windows 고유 읽기 권한/정션 테스트는 실기 검증이 필요합니다.

## 엔진 동작 확인에 사용한 자료

2026-10-26에 실제 엔진 소스의 관련 함수를 정적으로 읽어 확인했습니다. 엔진 코드를 프로그램에 포함하거나 실행하지 않았습니다.

- [MV 공식 CoreScript 저장소](https://github.com/rpgtkoolmv/corescript)
  - [Game_Interpreter.js](https://github.com/rpgtkoolmv/corescript/blob/master/js/rpg_objects/Game_Interpreter.js): 조건·변수·선택지·맵 이동·리소스 명령 파라미터 확인.
  - [Game_Event.js](https://github.com/rpgtkoolmv/corescript/blob/master/js/rpg_objects/Game_Event.js): findProperPageIndex의 역순 페이지 검사, meetsConditions의 플래그·임계값 확인.
  - [Decrypter.js](https://github.com/rpgtkoolmv/corescript/blob/master/js/rpg_core/Decrypter.js): 표준 16바이트 헤더와 본문 첫 16바이트 XOR 확인.
- [MZ 공식 Utils 소스](https://rpgmakerofficial.com/product/mz/rmmz_api/Utils.js.html): decryptArrayBuffer 헤더와 XOR 처리 확인.
- [실제 MZ 엔진 코드의 공개 사본](https://github.com/stak/rmmz-corescript/blob/master/rmmz_objects.js): command101의 speaker, command357의 플러그인 이름/명령/인자, MZ command285의 캐릭터 지정 모드 확인. 이 저장소를 공식 배포처로 표시하지 않습니다.
